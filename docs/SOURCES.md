# Источники

## Реализованы

### fixture
Локальный `data/fixture_orders.json`. Полный цикл без сети. Автоконтакт выключен на уровне capabilities (в тестах outreach идёт через mock-адаптер).

### rss
Список URL в `RSS_FEED_URLS`. Только HTTP GET публичных лент. HTTP 429 → ошибка и пауза на этом фиде. Автоконтакт недоступен.

### telegram
Telethon user session. Читает только каналы из `TELEGRAM_SOURCE_CHANNELS`, к которым аккаунт уже имеет доступ. Бот-токен **не** используется для чтения чужих чатов.

## Stubs (без имитации заказов)

### kwork / flru / freelance_ru
`probe()` проверяет достижимость сайта и возвращает `available=False` с причиной и альтернативами. `collect()` всегда пустой список + ошибка.

## Как добавить источник

1. Проверить ToS и наличие официального/разрешённого API.  
2. Реализовать `SourceAdapter` с честным `probe()`.  
3. Зарегистрировать в `sources/registry.py` и флаг в Settings.  
4. Покрыть тестом: unavailable без секретов; collect не фабрикует данные при запрете.
